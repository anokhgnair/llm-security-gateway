# Attribution

RAGShield Gateway is an independently developed and substantially extended local-first security gateway built using and modifying components derived from the Apache-2.0 licensed Taladari RAG Firewall project.

The current system extends the original retrieval-firewall concept into an end-to-end gateway with input security, indirect prompt-injection detection, local retrieval, document security, risk scoring, sensitive-data protection, output security, optional Ollama integration, audit logging, dashboard functionality, attack simulation, and automated evaluation.
